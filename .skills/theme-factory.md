# Skill: Theme Factory
## Purpose
Extend the DreamSync color palette while maintaining "Vibrant Professionalism".

## The Palette
- **Primary**: #2563EB (Core Action)
- **Secondary**: #FACC15 (Highlight/Attention)
- **Success**: #22C55E (Validation)
- **Error**: #EF4444 (Alert)
- **Safe Zone**: #ECFDF5 (Mental Health sections)

## Theming Rules
1. **Contrast First**: All themes must pass WCAG AA standards.
2. **Brutalist Accents**: Use high-contrast borders even in soft themes.
3. **Dynamic States**: Hover states should always involve a translation (translate-x, translate-y) and a shadow change.
4. **Consistency**: Use CSS Custom Properties defined in `globals.css`.
