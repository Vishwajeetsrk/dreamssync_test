# Skill: Figma Designer
## Purpose
Bridge the gap between Figma designs and Neo-Brutalist implementation.

## Mapping
- **Frames** -> `.neo-box` (border-2, bg-white, shadow-black)
- **Primary Buttons** -> `.neo-btn-primary` (Blue #2563EB)
- **Secondary Buttons** -> `.neo-btn-secondary` (Yellow #FACC15)
- **Shadows** -> Sharp, non-blurred offsets (4px 4px 0px 0px Black)
- **Typography** -> Space Grotesk (Headers), Inter (Body)

## Rules
1. Never use soft shadows (box-shadow with blur).
2. All borders must be sharp (radius-none or radius-md).
3. Foreground MUST be #000000 for maximum readability.
4. Spacing should be disciplined (multiples of 4px).
